Discover Spain
This project is a 5-page website about Spain. It shows my skills in building websites and my knowledge of the Spanish language. 🔗 [[Link to Project](http://gregarious-rostrum.poseidon.salford.ac.uk/index.html)]

What’s Inside
  - Home Page: A simple start with big buttons to help you find the different sections: Culture, Destinations, or Food.
  - History Timeline: A special page that shows the story of Spain from ancient times to today.
  - Culture: Information on famous Spanish events like Flamenco dancing and the La Tomatina tomato fight.
  - Food: A guide to tasty dishes like Paella and small snacks called Tapas.
  - Tourism: Highlights of top cities to visit, including Barcelona, Madrid, and Seville.

How I Built It
  - HTML5: Used to create the structure and text of the site.
  - CSS3: Used to make the site look professional with colors, nice layouts, and a design that works on phones and computers.
  - Design: Focused on making the site easy for anyone to use and navigate.

How to Run It
  - Download the files to your computer.
  - Open the file named index.html in your web browser.

Purpose of the Project
I created this to show:
  - Coding Skills: How I can build a large website with many pages that look good.
  - Language Skills: Using my Spanish language knowledge to write real information about the country.
